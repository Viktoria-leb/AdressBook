Результаты проекта:
- Реализовано консольное приложение на Java с объектно‑ориентированной архитектурой: выделил классы согласно принципу единственной ответственности.
- Настроено интерактивное меню с валидацией ввода пользователя: при выборе некорректной опции выводится сообщение об ошибке и меню показывается повторно.
- Реализован CRUD‑функционал для контактов: добавление (с проверкой на уникальность Ф. И. О. с учётом регистра и лишних пробелов), обновление существующих записей, удаление по ID и вывод полного списка контактов с нумерацией.
- Обеспечена корректная обработка сценариев: обновление контакта при совпадении Ф. И. О., поиск по ID, заполнение освободившихся мест в массиве при удалении.
- Соблюдены стандарты кодирования: использовал приватные поля с геттерами/сеттерами, переопределил методы equals и toString, избегал статических методов (кроме main), исключил магические числа за счёт констант, не оставлял закомментированный код.
